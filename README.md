# 내가 불판왕 (I'm the Grill King)

숯불 불판 위에 올라간 삼겹살을 **노릇노릇하게 굽고**, 딱 좋은 순간에 **싹둑 네 조각으로 잘라 접시에 내는** 불판 타이밍 게임입니다.
`왕전초 연산왕`·`타이머왕`·`눈치왕` 시리즈와는 다른, **먹음직스러운 숯불 불판 + 황금 불꽃** 스킨의 별도 게임이에요.

**바로 플레이:** https://chohanui2-home.github.io/samgyeop-grill/

## 게임 규칙

불판 칸마다 고기 한 줄이 놓이고, 시간이 지나면 아래에서부터 익어 갑니다.

`생고기(분홍)` → `익는 중(연갈색)` → **`✨ 황금 노릇노릇(딱 지금!)`** → `과익음(진갈색)` → `💀 탐(숯검댕이)`

- **한 번 탭 = 뒤집기(탁!)** — 앞면이 노릇해지면 고기를 톡 눌러 뒤집어요. 너무 이르면 *"아직 생고기예요!"*
- **한 번 더 탭 = 자르기(싹둑!)** — 뒷면까지 노릇해지면 반짝 표시가 뜨고, 그때 다시 탭하면(또는 **싹둑 자르기** 버튼) 가위로 네 등분해 접시로 서빙!
- **너무 늦으면** 연기와 함께 `앗, 탔어요!` — 불판에서 치워지고 콤보가 끊깁니다.
- 고기 아래 **굽기 게이지의 노란 띠**가 딱 지금 구간이에요. 띠 안에서 손을 쓰면 완벽한 접시!

## 6단계

| 단계 | 이름 | 불판 칸 | 목표 | 특징 |
|---|---|---|---|---|
| 1 | 1줄 연습 | 1칸 | 5접시 | 천천히 한 줄씩, 처음 배우기 |
| 2 | 2줄 굽기 | 2칸 | 6접시 | 두 칸을 번갈아 굽기 |
| 3 | 3줄 바쁘다! | 3칸 | 8접시 | 세 칸 동시 + 조금 센 화력 |
| 4 | 두께 섞임! | 3칸 | 8접시 | 빨리 익는 대패삼겹 · 보통 삼겹 · 느린 두툼 목살 |
| 5 | 손님 취향! | 3칸 | 8접시 | 말풍선 주문 `촉촉 미디엄` / `바싹 웰던`에 맞춰 굽기 |
| 6 | 불판왕 45초! | 4칸 | 45초 | 타임어택! 최대한 많은 접시를 서빙 |

화면 맨 아래 탭에서 언제든 단계를 바꿀 수 있고, 최고 기록을 낸 단계에는 ★ 표시가 붙습니다.

## 특징

- **한 손 초간단 조작** — 뒤집기도 자르기도 그냥 **고기를 톡 누르면** 끝. 오른쪽 아래 큰 `싹둑 자르기` 버튼은 지금 가장 잘 익은 고기를 알아서 골라 줍니다.
- **보이는 굽기 정도** — 고기 색이 분홍 → 연갈색 → 황금 → 진갈색 → 숯검댕이로 실제로 바뀌고, 기름 줄무늬 · 불판 자국 · 숯 자국이 시간에 따라 나타납니다.
- **점수와 콤보** — 완벽한 접시 100점 + 연속 콤보 보너스(최대 +50). 덜 익거나 탄 고기는 50점·20점.
- **두 캐릭터** — 작은 불꽃 요정 `불이`와 집게 든 마늘 친구가 고기가 노릇해지면 환호하고, 타기 직전이면 땀을 뻘뻘 흘리며 경고합니다.
- **효과음** — 지글지글, 뒤집기 `탁!`, 완벽 컷 `싹둑!+딩동`, 탄 연기 `푸쉬~` (Web Audio API, 음소거 가능, 외부 파일 0개)
- **결과 화면** — 별점과 등급(`👑 전설의 고기굽기 장인` · `🔥 회식 에이스` · `🐷 불판 꿈나무`), 서빙 수 · 완벽한 접시 · 최고 콤보 · 탄 고기, **다시 도전 · 다음 단계 · 친구에게 공유하기**
- **기록 저장** — 단계별 최고 점수 · 별점을 브라우저에 저장하고, 갱신하면 `새 기록!`
- **일시정지** — 잠깐 멈추면 고기가 타지 않고 그대로 멈춰 있어요.
- **앱처럼 설치** — 홈 화면에 추가하면 전체화면 앱처럼 열립니다(PWA 매니페스트 내장).
- PC에서는 `1`~`4` 키로 칸을, `Space`/`Enter`로 자르기, `Esc`로 일시정지를 쓸 수 있습니다.

## 파일

- `index.html` — 게임 전체가 들어 있는 **단일 파일**. 외부 CDN·폰트·이미지 0개(그림은 인라인 SVG, 소리는 Web Audio API). 파일 하나만 보내도 오프라인에서 그대로 열립니다.
- `app_template.html` — 빌드용 템플릿(아이콘 자리표시자 포함)
- `build.py` — 아이콘 주입과 단일 파일 규칙 검사 후 `index.html` 생성
- `test_app.py` — QuickJS로 게임 스크립트를 실행해 굽기 상태 머신 · 뒤집기/자르기 판정 · 두께 · 취향 주문 · 45초 타임어택 · 완주 · 기록 · 음소거 · 공유를 검사하는 테스트

## 다시 빌드하기

```bash
python3 build.py      # index.html 생성 (단일 파일 검사 포함)
python3 test_app.py   # 테스트 (quickjs 파이썬 모듈 필요)
```
